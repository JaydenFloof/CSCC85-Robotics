# Robot-Ragers

## Contributing

Team members are expected to follow the ***branch-per-developer*** strategy:
1. Create their own *local* branch of the form: `NAME_TASK`.

    (e.g., `sean_p1`, `david_p1`, `jayden_p1`, `sean_fleetbyte`, etc.)

2. Perform changes on their *local* branches.

3. After finalizing work on a *local* branch **and** receiving team approval, you may push from your *local* branch to the *main* branch.


### Additional Notes:
- The main branch is **NEVER** meant to break. If you have broken changes in your local branch, do not push those changes to the main branch.
- Directly pushing to the main branch is acceptable when posting the starter files for an assignment/exercise (do not include the zip along with the starter files) or for adding/changing/removing files which do not affect any assignments/exercises. The latter reason may require team approval.
